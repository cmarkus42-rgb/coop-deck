A web preview is only an address (`url` in `artefakt.json`). Here the marks from {{name}} carry the selector and the visible text of the element that was clicked; the reference is estimated. Look for the place in the source through the text, not through the selector alone. If you label elements with `data-coop-ref="…"` and `data-coop-label="…"` (optionally `data-coop-datei` for the file and `data-coop-zeile` for the line), the references become exact.
