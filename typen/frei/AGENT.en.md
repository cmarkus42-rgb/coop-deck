A free artifact is a folder with `index.html`; everything in it belongs to the project. Rules: load nothing from the network (store fonts and libraries locally), include `/lib/basis.css` for the shared look, and `/lib/coop.js` so that `coop zeigen --ref` can jump to a place. Free artifacts run sandboxed: no access to the deck, no network requests; the deck reloads the page when files in the folder change. Label content that {{name}} should be able to point at with `data-coop-ref="<id>"` and `data-coop-label="<readable name>"`.
