The project sheet is a Markdown file (usually `PROJEKT.md`) with fixed sections: Requirements (numbered V1, V2 …, binding), Facts and measurements (with kind and source), Decisions (with date and reason), Open, History. A sheet created in German carries the headings Vorgaben, Fakten und Maße, Entscheidungen, Offen, Verlauf; keep the headings the file already has. When {{name}} states a new requirement, enter it at once under the next number. You change or remove a requirement only when they say so. Reference for `--ref`: `datei:PROJEKT.md:<line>`.
