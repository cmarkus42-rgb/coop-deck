# Der Eingang

Im **Eingang** steht alles, was auf dich wartet, über alle Projekte hinweg. Die Zahl am Knopf und an den Projekten in der Leiste zeigt, wie viel es ist.

## Was dort erscheint

| Posten | Bedeutung | Was du tust |
|---|---|---|
| **Frage** | Die Session braucht eine Entscheidung und nennt Optionen. | Option anklicken, auf Wunsch mit Zusatz, oder eine eigene Antwort schreiben. |
| **Session** | Eine Session ist fertig oder wartet auf eine Freigabe. | **Hingehen** |
| **Hinweis** | Die Session weist auf etwas hin, oft mit einer Stelle im Artefakt. | Ansehen, dann **Gesehen** |
| **Schlange** | Aufträge warten, bis die Session Eingabe annimmt. | Warten oder **Jetzt senden** |
| **Anfrage ans Handy** | Die Session hat Fotos oder Ton vom Handy angefordert. | Am Handy liefern, siehe [Handy und Tablet](06-handy-und-tablet.md) |
| **Vom Handy** | Vom Handy ist etwas gekommen, das noch keine Session abgeholt hat. | Ansehen |
| **Dienst** | Ein Dienst soll allen Projekten angeboten werden und braucht deine Bestätigung. | **Ansehen und bestätigen** |

## Fragen

Eine Frage beantwortest du im Eingang; die Antwort wird in die Session getippt. Klärt ihr die Sache im Gespräch, räumt das Deck die Frage von selbst ab, sobald die Session weiterarbeitet. Die Session kann eine Frage auch zurückziehen. Mit **Erledigt** nimmst du sie ohne Antwort aus dem Eingang.

Viele Fragen auf einmal stellt eine Session besser als Fragebogen, siehe [Artefakte](03-artefakte.md).

## Hinweise im Artefaktfenster

Ein Hinweis erscheint zusätzlich als Band über der Ansicht, auf die er sich bezieht. **Ansehen** springt an die Stelle.
