# Markieren und Rückmeldung

Statt zu beschreiben, wo etwas nicht stimmt, zeigst du darauf. Jede Marke bekommt eine Nummer und deinen Satz dazu. Die Session erhält eine Textdatei, die je Marke sagt, was gemeint ist; das Bild liegt nur bei.

## So geht es

1. Öffne rechts die Ansicht, um die es geht. Das geht in jedem Reiter, auch auf einer laufenden Seite.
2. Wähle in der Werkzeugleiste ein Werkzeug und markiere.
3. Schreibe zu jeder Marke, was anders sein soll. Eine allgemeine Anmerkung zur Ansicht ist möglich.
4. Wähle das Ziel: die aktive Session, eine andere laufende oder eine neue Session mit diesem Auftrag.
5. **{{ui.rueck.vorschau}}** zeigt den Text vorab. **{{ui.rueck.senden}}** schickt ihn los.

## Die Werkzeuge

| Werkzeug | Wofür |
|---|---|
| **{{ui.werkzeug.zeigen}}** | Ein Element anklicken. Die Marke weiß, was gemeint ist: in typisierten Artefakten etwa den Roadmap-Punkt oder die Zeile der Datei. |
| **{{ui.werkzeug.rahmen}}** | Einen Bereich aufziehen. |
| **{{ui.werkzeug.pfeil}}** | Einen Pfeil ziehen; gemeint ist, worauf die Spitze zeigt. |
| **{{ui.werkzeug.freihand}}** | Frei einkreisen. |
| **{{ui.werkzeug.text}}** | Einen Punkt setzen und beschriften. |

Wo das Deck den Bezug nur schätzen kann, steht das in der Rückmeldung. Die Session nennt dann ihr Verständnis, bevor sie baut.

## Was danach geschieht

Arbeitet die Session gerade, wartet die Rückmeldung in der Schlange. Hat die Session sie abgearbeitet, meldet sie sie als erledigt. **{{ui.verlauf}}** zeigt alle Rückmeldungen zu einem Reiter, offen und erledigt, mit dem Bild vorher und nachher.
